## 🚀 Core Ecosystem & Featured Projects

- 📱 **[Arplication](https://github.com/Aruthtale/Arplication)**  
  *Modular Mobile Utility & Media Suite* — Built with React, Vite, and custom native Capacitor Android plugins. Features offline-first audio resolution, background task processing, and direct hardware integration.

- 🎫 **TiketKita (Arketing)**  
  *Enterprise Event Ticketing SaaS* — Fullstack platform designed for flash sales and instant transactions. Engineered with on-access lazy expiration quotas, clean CQRS, and consumer-grade UX.

- 📡 **Arumation**  
  *Autonomous Content Pipeline & Software Radar* — Headless intelligence pipeline that tracks GitHub releases and tech changelogs every 8 hours, summarizing insights via local AI agents.

- 🤖 **[Aruthtale Bot](https://github.com/Aruthtale/Aruthtale_Bot)**  
  *Intelligent AI Gateway & Assistant* — Multi-platform automation bridge connecting Telegram, local Linux services, and autonomous agent backends.
